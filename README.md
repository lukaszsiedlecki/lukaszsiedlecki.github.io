# Hi, I'm Łukasz 👋

I'm a software engineer who's spent the last decade-plus in the Java and Spring world, mostly building things that deliver actual business value. Lately I've been pulling my focus down a layer, closer to the metal, because I think you can't really call yourself a complete engineer if you only know the code and not the platform it runs on.

## What this blog is about

I started writing here to close the gap between "application developer" and "infra person" in my own head. I'm a Certified Google Professional Cloud Architect and work with cloud-native tech day to day, but I still think the best way to actually understand something is to run it yourself and watch it break. So I keep a Proxmox homelab with a Talos Linux Kubernetes cluster, which is basically my sandbox for breaking things on purpose (and sometimes by accident).

## What I write about

I don't think broad knowledge is enough anymore - going deep on a few things is what actually matters. So this is where I dig into:

- **Linux internals** - not just admin commands, but how the system actually works
- **Kubernetes** - building clusters, then taking them apart to see why they broke
- **The JVM** - memory models, GC tuning, bytecode, that kind of thing
- **Observability** - distributed tracing, OpenTelemetry, eBPF, beyond just grepping logs
- **Infrastructure as code** - Terraform, GitOps, and the reality of managing it long-term
- **Networking** - HTTP/3, QUIC, gRPC, CNI plugins
- **Algorithms** - the fundamentals that still matter under all the abstraction

## What can I help you with

If you want to reach out or need a hand, here's roughly where I'm useful:

- **Java** - core language, JVM internals, performance and GC tuning, concurrency
- **Spring** - Spring Boot, Spring Data, Spring Security, building and troubleshooting production services
- **Docker** - writing sane Dockerfiles, multi-stage builds, image size and layer caching, debugging containers
- **Kubernetes** - deployments, networking, troubleshooting clusters, running workloads reliably (including on bare-metal/homelab setups)
